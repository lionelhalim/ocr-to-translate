### Requirements
- python >= 3.10

`pip install -r requirements.txt`

### Running python script
`python main.py`

### Running as .exe
- `pyinstaller --noconfirm --onefile --windowed --name main.py`
- check dist project `dist` folder, there should be file `main.exe`

### Using the program
- `ctrl+shift+alt+d` for shortcut c*a*pture. Or you can click the button for trigger capturing state.
